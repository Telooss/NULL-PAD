# Ecarts avec l'artefact nullctl

Les fichiers de ce dossier sont la copie telle quelle de l'artefact. Les fichiers servis par l'appli, dans `ui/web/`, en different ainsi :

- `web/css/bundle.css` : l'`@import` Google Fonts de la premiere ligne est remplace par des `@font-face` locaux (`web/fonts/`, woff2 latin). Autre ecart (Task 9, barre des profils qui passait a la ligne sous 1440 px) : `white-space: nowrap; flex-shrink: 0` sur `.nc-pill` et `.nc-newprofile`, `flex-shrink: 0` sur `.nc-status`, `white-space: nowrap` sur `.nc-btn`, `.nc-slot` en `flex: 0 1 auto; min-width: 150px` (au lieu de `min-width: 170px`) et peut retrecir, `.nc-sticker` coupe par une ellipse. Le reste est identique a `design/components/bundle.css`.
- `web/js/bundle.js` : copie de `design/components/bundle.js` (il doit etre sous `web/`), avec ces modifications de `pad3d`, marquees `nullctl` dans le code (Task 7, regles de performance du spec §6) :
  - densite de pixels plafonnee a 1,5 au lieu de 2 ;
  - `render()` ne dessine plus directement : il demande une image via un seul `requestAnimationFrame` en attente (les appels se regroupent) ; rien n'est dessine si `document.hidden`, et un `visibilitychange` redemande une image au retour ;
  - textures de legende et du nice!view redessinees seulement si leur contenu change ; une legende peut etre `[l1, l2]` (deux lignes, 50 px) ;
  - placement de la camera dans `aim()`, refait par `resize(w, h)`, qui redessine aussitot (le `setSize` vide le canvas ; image en attente annulee), seulement sur un vrai changement de taille ;
  - survol factorise dans `hoverOn()`, plus un `pointerleave` qui l'efface ;
  - nouvelles fonctions renvoyees : `hover(piece)`, `press(piece, down, dz=1.5)` (enfoncement le long de z avec la legende et le contour, lueur violette), `pick(x, y)`, `resize`, `dispose`, `invalidate`, `frames()`.
- `web/css/tokens.css` : variables `:root` et classes de texte (`.ui-small`, ...) ecrites depuis `tokens.json`. Les previews de l'artefact les recevaient de la plateforme.
- `web/css/app.css` : `.nc-app` prend `100vw x 100vh` au lieu de 1440x900 fixes, plus un survol des boutons de fenetre. Mode configuration (Task 9, ecrans sans maquette, tokens existants, aucun effet) : cadre de scene `violet-500`, bandeau `.nc-configbar`, champs de saisie `.nc-input` (meme boite que `.nc-file`), `.nc-row`, `.nc-step(s)` (etapes de macro, sous-editeurs de bascule), `.nc-panel-body` (defilement du panneau), un `input[type=range]` transparent sur la piste de `.nc-slider`, boite modale `.nc-modal` (un `.nc-panel` sur fond assombri). Largeur (fix Task 9) : `.nc-app` en `grid-template-columns: minmax(0, 1fr)`, `.nc-main` en `minmax(0, 1fr) 400px`, `min-width: 0` sur le panneau et ses sections, `.nc-seg` passe a la ligne, description de `.nc-current` coupee par une ellipse ; sous 1680 px, les libelles (`.lbl`) des pastilles, de « Nouveau profil », « Configurer », « Réglages » et « Démarrer le moteur » sont masques (icone seule, infobulle `title`). « Enregistrer » et « Annuler » gardent leur libelle.
- `web/assets/nullpad.json` : copie de `design/assets/Modele/nullpad.json` (charge a l'execution, Task 7).
- `web/vendor/` : three.js 0.160.0 et lucide 0.344.0 locaux, a la place des CDN des previews.
